1. Descrição do Projeto:
Hoje em dia, muitos jogadores enfrentam dificuldades para encontrar rapidamente
informações completas e atualizadas sobre jogos, como sinopse, imagens,
plataformas disponíveis e preços. Normalmente, é necessário visitar vários sites para
obter esses dados, o que pode ser demorado e confuso. Além disso, a comparação
de preços entre plataformas digitais (como Steam, Epic Games, PlayStation Store,
etc.) nem sempre é clara ou acessível.
2. Objetivo do Projeto:
Criar um site centralizado onde os usuários possam:
● Navegar por jogos disponíveis no mercado.
● Visualizar a sinopse, imagens e plataformas em que o jogo está disponível.
● Ver em tempo real os preços do jogo em diferentes plataformas.
● Facilitar a escolha da plataforma com melhor custo-benefício, redirecionando
o usuário diretamente para a compra no site mais barato.
